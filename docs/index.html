Fovea is the governed operating layer between people, models, warehouses, and production systems. You do not need to understand the kernel. Act as Maya, ask a named question, and read the evidence pane. It answers with evidence, or it stops.

Principles that will not be reopened casually

  1. 01The OS is the control plane, not the UI.
  2. 02User-invoked permissions use intersection, never union.
  3. 03Personal memory is isolated.
  4. 04Arbitrary tools and plugins are not allowed.
  5. 05Agents cannot deploy their own modifications.
  6. 06Production runs only signed, verified artifacts.
  7. 07Tool output is untrusted data, not policy.
  8. 08Abstention is a success state.
  9. 09Stage progression is evidence-driven.

Run locally

git clone https://github.com/salahuddinuqaili/fovea
cd fovea
npm install
npm test
npm run dev

Requires Node 22. Open the app — you are Maya Chen. No account is required. Ask north-star revenue, then “Investigate the dip last week.” Propose a sandbox write as Maya, approve as Jordan. Switch to Alex Voss, issue a named grant, ask north-star as Maya, then revoke. Production tables stay blocked. Read the in-app operator guide after Command loads.
