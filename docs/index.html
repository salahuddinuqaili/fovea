Reads

Evidence or stop

A canonical metric returns a number, the query, and provenance. If the name is ambiguous, Fovea refuses to guess. That is success.

Writes

Someone else signs

An approver who is not the requester decides an exact action hash. A short-lived credential may run in sandbox. Production stays gated.

Policy

No one does everything

Permissions never union across desks. Tool output, tickets, and READMEs are data — not policy. A grant is one person, one tool, one task.

How it works

Ten minutes on the analyst desk. If these four things happen, the control plane is working. The in-app Guide has the rest.

  1. Ask a named metric “What was north-star revenue last week?” returns a supported number, the SQL, and provenance.
  2. Ask something vague “How is revenue doing?” abstains. More than one definition exists. Fovea will not pick one.
  3. Propose a sandbox write The analyst cannot approve their own hash. The approver mints a short-lived sandbox credential. Replay adds no rows. Production tables stay out of scope.
  4. Issue a named grant — then revoke it Only the OS owner or security owner can. One person, one tool, one task, a risk ceiling. Matching reads may continue. Writes stay hash-bound. The grant never becomes a global switch.

Who decides

Each desk is a job, not a login. Permissions intersect — they never union. There is no admin who can do everything.

Hard stops

Product rules, not UI copy. A confident wrong number is a failure. A refusal is not.

  • If the metric name is ambiguous, Fovea abstains. Named canonical metrics only.
  • Production writes and backfill execution stay disabled.
  • The person who requested a write cannot approve it. Approval binds one exact hash.
  • Unsigned or tampered releases cannot load. There is no skip-signature path.
  • Personal memory is isolated and never written to the shared snapshot.
  • There is no global autonomous switch — not in this version, not later.

Not in this tree: SSO, a live warehouse DSN, production execution, arbitrary plugins.
